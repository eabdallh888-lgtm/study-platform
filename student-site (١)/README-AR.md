# دليل تشغيل المنصة (٣٠ دقيقة تقريباً، ومجاناً)

## الموجود في المجلد
| الملف | وظيفته |
|---|---|
| `index.html` | موقع الطلاب: الدروس + بطاقات الحفظ + الاختبار + تقدّمي |
| `admin.html` | لوحة المعلم: رفع ديكات HTML و PDF وفيديوهات وروابط يوتيوب |
| `config.js` | إعدادات الموقع (اسمه + مفاتيح Supabase) |
| `supabase.sql` | إعداد قاعدة البيانات والتخزين (بيتنفّذ مرة واحدة) |
| `content/` | الدروس الخمسة الجاهزة (ديك + PDF لكل درس) |

> **الموقع شغال من أول لحظة** بالدروس الخمسة الجاهزة، حتى قبل ما تعمل الخطوات دي. الخطوات مطلوبة بس عشان **ترفع دروس جديدة** من لوحة المعلم.

## أولاً: قاعدة البيانات (Supabase، مجانية)
1. ادخل على **supabase.com** → Sign up → **New project** (اختار أقرب منطقة، واحفظ كلمة سر قاعدة البيانات).
2. من القائمة: **SQL Editor** → New query → الصق محتوى `supabase.sql` كله → **Run**.
3. من **Project Settings → API** انسخ:
   - **Project URL**
   - **anon public key**
4. افتح `config.js` وحطهم:
   ```js
   supabaseUrl:'https://xxxx.supabase.co',
   supabaseKey:'eyJ...'
   ```
5. **حساب المعلم:** Authentication → Users → **Add user** → Create new user (إيميلك + كلمة سر قوية).
6. **أمان مهم:** Authentication → Sign In / Providers → Email → اقفل **Allow new users to sign up** (عشان محدش غيرك يسجّل ويرفع).

## ثانياً: النشر (اختار طريقة واحدة)
- **Netlify (أسهل):** ادخل `app.netlify.com/drop` → اسحب المجلد كله → هتاخد رابط. تقدر تغيّر اسمه من Site settings.
- **Cloudflare Pages:** Workers & Pages → Create → Pages → Upload assets → ارفع المجلد.
- **GitHub Pages:** ارفع المجلد في مستودع → Settings → Pages.

بعد أي تعديل على `config.js` أعد رفع المجلد.

## ثالثاً: الاستخدام
- **الطلاب:** يفتحوا الرابط على أي جهاز. تقدّمهم بيتحفظ على أجهزتهم.
- **أنت:** افتح `رابط-الموقع/admin.html` → سجّل دخول → **درس جديد** → اختار الملفات:
  - **ديك تفاعلي (HTML):** ارفع ملف `.html` زي اللي عملناه (بيتخزن في قاعدة البيانات ويشتغل جوّه الموقع).
  - **PDF / فيديو (ملف):** بيتخزن في Supabase. الحد **٥٠ ميجا** للملف الواحد في الخطة المجانية.
  - **فيديو يوتيوب:** للفيديوهات الطويلة: ارفعه على قناتك بوضع **غير مدرج** والصق الرابط.
- **تضيف دروس جاهزة جديدة للمجلد نفسه:** ضيف الملف في `content/` وسطر في `content/manifest.json`.
